Marginalia

Messy, partial, raw insights worth revisiting. Click to read.

Sticky Note
Taste as a calibrated compass

Taste is a compass with good stories. It points before you have proof. Follow it long enough to earn the map. Then check the map against the world.

Sticky Note
Default to draft

Default to draft, not done. The draft keeps you curious. Curiosity keeps the door open. Closed doors breed stale work.

Sticky Note
Meetings as mirrors

Meetings are mirrors with terrible lighting. Fix the system, not the reflection. Or at least dim the glare. Clear rooms make clearer work.

Sticky Note
Feature diet

Features are snacks. Ship a meal. Leave room for dessert. Sugar is not a roadmap.

Sticky Note
Error budget for pride

Keep an error budget for pride. Spend it on learning, not denial. Brag later, iterate now. Humility is fast feedback.

Sticky Note
Naming is modeling

Naming is modeling with fewer calories. If the name is wrong, the map is wrong. Rename early, save steps. Clarity is cheaper than cleanup.

Sticky Note
Version zero honesty

Version zero should be honest. It can be ugly, but it cannot be vague. Ugly is fast, vague is slow. Truth beats polish on day one.

Sticky Note
Delight in the footnote

Delight hides in the footnote. Write the small promise and keep it. Tiny wins earn long trust. Trust is a compound interest.

Sticky Note
Ship the sketch

Ship the sketch, not the cathedral. You can add arches later. Stone waits, feedback does not. Build with the wind on your side.

Sticky Note
Feedback loop picnic

Feedback loops are picnics. Invite the right people and bring a blanket. Leave room for surprise fruit. Bad guests still eat your time.

Sticky Note
Keyboard economy

Keyboard economy: every shortcut is a tiny gift. Give a few, not a hundred. Too many and the gift is debt. Good tools reduce apology time.

Sticky Note
Friction log: the setup tax

Friction log: setup is a tax with no receipt. Pay it once, document it twice. Every minute saved is a small wage. Spend it on thinking, not retyping.

Sticky Note
The gentle constraint

A gentle constraint is a friendly fence. It keeps the garden possible. Without it, you mow a forest. Boundaries let play stay playful.

Sticky Note
Trust the checklist

Trust the checklist when your brain is tired. It is the quiet coworker. It never forgets lunch. Respect the boring guardian.

Sticky Note
Bug as biography

Every bug is a tiny biography. It tells you how the system grew up. Listen, then discipline gently. The origin story is the fix.

Sticky Note
Instrument the hunch

Instrument the hunch. Let curiosity wear a lab coat. Then let it take notes. Data is a witness, not a judge.

Sticky Note
Docs as future self

Docs are love letters to future you. Write one before you forget the plot. Your memory is not versioned. Neither is your patience.

Sticky Note
Smooth edges

Smooth edges turn strangers into users. Rough edges turn users into critics. Sandpaper the sharp bits. Polish is a form of respect.

Sticky Note
Guardrail glow

Guardrails glow when you hit them. Make them soft enough to learn. Hard rails teach only fear. Good rails teach better paths.

Sticky Note
The slow yes

A slow yes beats a fast maybe. It leaves fewer ghosts. Clarity is kinder than speed. Decisions are a form of care.

Sticky Note
Roadmap weather

A roadmap is weather, not fate. Pack a jacket anyway. Forecasts lie, preparation helps. Keep walking, keep adjusting.

Sticky Note
Runtime over confidence

Confidence is not a permission model. Good systems separate suggestion from action. The runtime decides what becomes real. That is where trust starts.

Sticky Note
The pauseless valley

The pauseless valley is real. It is not what it says, but the silence it skips. A good pause is a comma for trust. Give the listener space to breathe.

Sticky Note
No run, no memory

If a step has no run context, it has no accountable history. Thread the run id through everything. Debugging gets cheaper immediately.

Sticky Note
Permission is architecture

Policy is not a final checklist. It is the shape of your runtime. Allow, deny, ask. Three verbs, cleaner systems.

Sticky Note
Proof beats polish

A fluent answer can still be wrong. A verified artifact can still teach. Always prefer evidence to elegance. Reliability follows that habit.

Sticky Note
Trace is your second brain

When incidents happen, memory drifts. Trace logs do not. Record each decision as it happens. Future-you will thank present-you.

Sticky Note
Ranking is not the whole game

A click is one surface. A citation is another. Build pages that survive both tests.

Sticky Note
Definition first, flourish later

If your first paragraph is vague, retrieval systems move on. State the idea plainly, then expand.

Sticky Note
Entity drift breaks memory

Same idea, new label, new label, lost context. Consistency is discoverability insurance.

Sticky Note
Citations follow confidence

Specific claim. Clear section. Verifiable context. That is citation gravity.

Sticky Note
Observe before you optimize

First trace. Then tune. Else, you optimize stories. Not systems.

Sticky Note
Retrieve first

Source before certainty. Context before confidence. Claim after evidence. That order is the point.

Sticky Note
Complexity budget: spend with care

Complexity budget: spend it like you cannot expense it. Simplicity is the interest you keep. Debt collectors wear friendly UI. Pay early, or pay forever.

Sticky Note
Crawl first, then charm

A page that cannot be reached does not get to be persuasive later.

Sticky Note
Assembly creates the feeling

What users call "smart" is often a well-arranged system wearing one model's voice.

Sticky Note
A stop is part of the system

If the loop cannot pause, it is not autonomous. It is just unobserved.

Sticky Note
Language needs rails

Natural language is generous. Execution should not be.

Sticky Note
Drift diary: small shifts

Log the small shifts before they become a broken workflow. Tiny drift, big detour. Catch it early, steer with a grin. Future you will call it kindness.

Sticky Note
Quiet undo

The best feature is a calm undo. Build for the moment you regret, not the moment you ship. Mercy scales better than speed. Make it easy to try again.

Sticky Note
Scope creep with manners

Scope creep walks in wearing a polite hat. Ask for its badge. Then check its pockets. Not every guest gets a key.

Sticky Note
Prototype promissory note

A prototype is an IOU from your future self. Keep it small, keep it honest. Interest is paid in rewrites. Sign it only if you mean it.

Sticky Note
Latency as tone

Latency is tone, not just time. A pause can be a hug or a shrug. Tune it like you tune a voice. Your product is speaking.

Sticky Note
Multi-agent systems amplify both capability and failure

Handoffs are load-bearing elements. Context loss at handoff is the most common failure. Without observability, you cannot debug orchestration. Add tracing before you need it, not after.

Sticky Note
Safety constraints must be architectural, not configurable

Autonomy without boundaries is unreliable. Architectural constraints cannot be bypassed. Advisory constraints fail when pressure is highest. Safety is a design property, not a configuration choice.

Sticky Note
Enterprise AI requires governance contracts before architecture

Governance contracts before architecture. Policy ownership must precede system design. Adoption is earned, not deployed. The blueprint survives when affected teams are involved early.

Sticky Note
Contracts make integrations safe

Define the contract before the integration. Validate outputs at the boundary. Decouple upstream model variance from downstream data systems.

Sticky Note
The logic void is where system design begins

Fluency is not a validity signal. The void produces confident wrong answers. Uncertainty signaling is a core property. Honest systems earn more trust.

Sticky Note
Semantic Caching

Semantic caching maps natural language queries to vector spaces. If a query falls within the similarity threshold, we bypass the LLM. But loose boundaries lead to cache collisions and serve stale data. Optimize for safety by raising the similarity gate.

Sticky Note
Sticky Notes 001: first signals

Small signals, kept close. Raw words before the shape. The start stays visible and useful. This is where momentum learns your name.

Sticky Note
Sticky Notes: the scraps that move us

A scrap of language, passed hand to hand. We climb on small words and call it progress. Keep the raw signal. It still hums. The note is a seed, not a verdict.
