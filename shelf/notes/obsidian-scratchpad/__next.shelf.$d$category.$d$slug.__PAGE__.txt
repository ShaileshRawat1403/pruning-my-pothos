2:T915,<p>An Obsidian scratchpad is one note per day that you write into without organising anything: a timestamp, a fragment, the next fragment. It takes two core plugins, Daily notes and Templates, and about five minutes to set up.</p>
<h2 id="the-setup">The setup</h2>
<ol>
<li><p>Create two folders in your vault: <code>Scratchpad</code> and <code>Templates</code>.</p>
</li>
<li><p>In <code>Templates</code>, create a note called <code>scratchpad</code> with this in it:</p>
<pre><code class="language-markdown"># {{date}}

- {{time}}
</code></pre>
</li>
<li><p>Turn on the <strong>Templates</strong> core plugin and set its template folder to <code>Templates</code>.</p>
</li>
<li><p>Turn on the <strong>Daily notes</strong> core plugin and set:</p>
<ul>
<li><strong>Date format</strong>: <code>YYYY-MM-DD</code></li>
<li><strong>New file location</strong>: <code>Scratchpad</code></li>
<li><strong>Template file location</strong>: <code>Templates/scratchpad</code></li>
</ul>
</li>
<li><p>Give two commands a hotkey: <strong>Open today&#39;s daily note</strong>, and <strong>Templates: Insert current time</strong> for each new fragment.</p>
</li>
</ol>
<p><code>{{date}}</code> and <code>{{time}}</code> are filled in when the note is created, as described in <a href="https://obsidian.md/help/plugins/templates">Obsidian&#39;s Templates help</a>; the Daily notes settings are on <a href="https://obsidian.md/help/plugins/daily-notes">its own help page</a>. Checked 2026-10-21.</p>
<h2 id="how-i-use-it">How I use it</h2>
<p>Working notes. Subject to change.</p>
<p>What I keep: a daily file with timestamps and short fragments.</p>
<p>Why it works: low friction beats perfect structure when ideas are early.</p>
<p>Where it fails: long-term retrieval without periodic cleanup.</p>
<h2 id="the-cleanup-that-keeps-it-useful">The cleanup that keeps it useful</h2>
<p>The failure above has a cheap fix: once a week, read the week&#39;s scratchpads and move anything still alive into a proper note, then leave the scratchpad alone. The daily files stay as a log; the ideas move to where you will look for them later.</p>
<p>A fragment that keeps coming back can be a decision waiting to be written down. The longer argument for writing those down is <a href="/self/decision-logs-beat-memory/">decision logs beat memory</a>.</p>
