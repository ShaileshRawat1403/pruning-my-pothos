Upload Everything, Read Nothing

After this, you can give an assistant your documents and check, with five questions, whether what you uploaded is what it answers from.

You uploaded the folder and asked a question. The answer sounded like your documents, and it might have been. Between your files and the answer, a document can fail to be read, lose to an older copy, never get picked for this question, or get picked and ignored, and every one of those looks the same from the chat box. A few questions whose answers you already know show which one happened.

The tools, from their own docs

  • Claude Projects

    For: A project's knowledge: documents you upload once and every chat in the project can draw on. Its help page says that as project knowledge approaches the context limit, it switches to a retrieval mode.

    Does not: Showing you which passages it read for a given answer. Ask for the quote and check it.

    As of 2026-10-02

  • OpenAI file search (API)

    For: For apps you build: the model searches files you uploaded, by meaning and by keyword, and its answers carry citations naming the file.

    Does not: Promising the cited passage supports the answer. A citation names where it looked; whether it read it right is still yours to check.

    As of 2026-10-02

Where this stops

Five questions show whether the evidence reached it for those five. They cannot tell you which passages it will pick for the next question, and an answer that quotes the right page can still draw the wrong conclusion from it. When a check fails, the article below walks the stages in order to find where the document was lost.
