# PocketFabric website adaptation

Native Stack case-study page, `/stack/pocketfabric/`. Not a Systems article,
a live dashboard, or a deployment control. The client component is prerendered
in the static export; state is local and changes only on reader input.

## Sources and scope

- Author-supplied prototype: `pocketfabric-node1/docs/journey/pocketfabric-journey.html`,
  read at commit `e48a8ca0ff7acc7f28e07b30b163ac63c7ebf378` (private operations repo).
  This is narrative input, not the public evidence citation.
- Shailesh Rawat, *A Second Life Under Constraints*, v1.2, 31 October 2026:
  https://doi.org/10.5281/zenodo.23836212
- Shailesh Rawat, *PocketNode Functional Validation*, v1.2, 31 October 2026:
  https://doi.org/10.5281/zenodo.23836251

Observations are attributed to the author's reports. Drawings reconstruct
reported mechanisms; none are live readings. No new firsthand observations
or author attestation are generated by this adaptation.

## Editorial changes from the prototype

- Use the site's shell, theme tokens, fonts and SpotlightCard pattern.
- Keep the original HTML unchanged in its source repository.
- Replace auto-play and global script listeners with explicit React controls.
- Qualify historical service and reboot observations; omit the sample green
  health console and any implication of current 24/7 availability.
- Embeddings passed predefined tolerances; they were not exact.
- Do not add model-load and warm-up counters: they overlap. Compare the
  measured end-to-end totals and internal compute counters separately.
- Omit the meaning-similarity scatter plot: it is outside these two reports.
- Disclose single-device scope, private raw logs, AI assistance, self-funding
  and absence of journal peer review. No em dashes or promotional claims.
