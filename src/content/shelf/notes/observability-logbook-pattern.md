This is the smallest review loop I have found that still creates learning.

What I keep: one table with decision, evidence, outcome, and next guardrail.

Why it works: it converts incidents into repeatable design changes instead of memory debates.

Where it fails: if teams skip weekly review, the logbook becomes archive theater.
