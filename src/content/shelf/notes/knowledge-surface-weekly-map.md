This weekly pass keeps my notes from becoming a static archive.

What I keep: one short map of core entities, stale pages, and missing links.

Why it works: each pass improves reuse quality, so future writing starts from structure instead of search.

Where it fails: if naming rules change every week, the map adds noise instead of clarity.
